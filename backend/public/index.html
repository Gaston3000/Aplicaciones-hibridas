API WORLD CUP 26

API REST de las sedes oficiales del Mundial 2026. Autenticación con JWT, base de datos MongoDB y tres entidades: Usuario, Estadio y Categoría.

Usuarios

  • POST /api/usuarios/registro — crear una cuenta
  • POST /api/usuarios/login — iniciar sesión (devuelve el token)
  • GET /api/usuarios/perfil — datos del usuario logueado token
  • GET /api/usuarios — listar usuarios admin
  • POST /api/usuarios — crear usuario admin
  • GET /api/usuarios/:id — ver un usuario admin
  • PUT /api/usuarios/:id — editar usuario admin
  • DELETE /api/usuarios/:id — eliminar usuario admin

Estadios

  • GET /api/estadios — listar sedes
  • GET /api/estadios/:id — ver una sede
  • POST /api/estadios — crear sede admin
  • PUT /api/estadios/:id — editar sede admin
  • DELETE /api/estadios/:id — eliminar sede admin

Categorías

  • GET /api/categorias — listar categorías
  • GET /api/categorias/:id — ver una categoría
  • POST /api/categorias — crear categoría admin
  • PUT /api/categorias/:id — editar categoría admin
  • DELETE /api/categorias/:id — eliminar categoría admin
Las rutas marcadas necesitan el header Authorization: Bearer <token>. Las marcadas como admin además requieren rol de administrador.
