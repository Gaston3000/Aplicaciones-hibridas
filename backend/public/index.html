API Limpieza Total

Backend de productos de limpieza con usuarios, login y JWT.

Endpoints

  • POST /api/usuarios/registro — crear usuario
  • POST /api/usuarios/login — iniciar sesion (devuelve token)
  • GET /api/productos — listar productos
  • GET /api/productos/:id — ver un producto
  • GET /api/categorias — listar categorias

Las rutas de escritura (POST/PUT/DELETE de productos y categorias) requieren el token en el header Authorization: Bearer <token>.
