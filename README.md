# Aplicaciones Híbridas — Desafíos semanales

Repositorio con los cinco desafíos semanales de la materia **Aplicaciones Híbridas** (DW4).
Adaptados al dominio de **productos** (rubro limpieza).

## Índice

| Semana | Tema | Carpeta |
|--------|------|---------|
| 01 | Callbacks, Promesas y Async/Await | [Semana-01](./Semana-01) |
| 02 | Módulos Nativos — CommonJS + ES Modules (esPrimo) | [Semana-02](./Semana-02) |
| 03 | Primer servidor con Node (`http` nativo) | [Semana-03](./Semana-03) |
| 04 | Servidor con Express.js (películas + productos) | [Semana-04](./Semana-04) |
| 05 | Estructura MVC (productos + categorías) | [Semana-05](./Semana-05) |

## Cómo correr cada desafío
Entrar en la carpeta correspondiente y seguir el `README.md` de cada semana:
```bash
cd Semana-04
npm install
npm start
```

## Stack
- Node.js (módulos nativos y ES Modules)
- Express.js 4.x
- dotenv
