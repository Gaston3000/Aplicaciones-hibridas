# Aplicaciones Híbridas - Desafíos semanales

Repo con los desafíos semanales de la materia Aplicaciones Híbridas (DW4).
Todo lo hice sobre el rubro limpieza (productos).

## Desafíos

- Semana-01: Callbacks, Promesas y Async/Await
- Semana-02: Módulos nativos (CommonJS + ES Modules) con la función esPrimo
- Semana-03: Primer servidor con Node (http nativo)
- Semana-04: Servidor con Express.js (peliculas + productos)
- Semana-05: Estructura MVC (productos + categorias)
- Semana-06: API con MongoDB, usuarios, login y JWT
- Semana-07: Home en React (catálogo de productos)
- Semana-08: Formulario de registro en React (conectado a la API)
- Semana-09: Rutas con React Router + Login + Detalle

## Como correr

Cada semana tiene su propio README. En general:

```
cd Semana-04
npm install
npm start
```
