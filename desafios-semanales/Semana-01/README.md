# Semana 01 — Callbacks, Promesas y Async/Await

Tres versiones del mismo flujo asincrónico aplicado a productos.

## Archivos
- `callbacks.js` → Parte 1: tareas encadenadas con callbacks.
- `promesas.js` → Parte 2: mismas tareas como promesas ejecutadas en paralelo con `Promise.all`.
- `async-await.js` → Parte 3: cadena con `async/await` y `try/catch`.

## Cómo correr
```bash
node callbacks.js
node promesas.js
node async-await.js
```
